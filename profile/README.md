## About us

TETYM Micro SaaS is the product hub of Baku State University's Student Scientific-Technical Creativity Center. We take small, focused software ideas from concept to launch: planning, design, development, deployment and growth.

## What we build

- **Micro SaaS products** that solve one problem well
- **Web applications** with React, Next.js and Node.js
- **Mobile apps** with React Native
- **AI-powered tools** and integrations
